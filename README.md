<a name="português"></a>
## 🇧🇷 Português

Uma galeria web interativa de cidades ao redor do mundo, permitindo filtrar destinos por continente e visualizar imagens ampliadas com curiosidades e fatos interessantes sobre cada local.

🔗 **Acesse o projeto online:** [brunossilva12-creator.github.io/GaleriaInterativa](https://github.io)

### ✨ Funcionalidades
- **Filtro por Continentes:** Navegação dinâmica entre todas as cidades ou filtragem específica por Ásia, Europa e América.
- **Visualização Ampliada (Modal):** Clique nas imagens para abri-las em tela cheia com navegação entre os itens (`❮` e `❯`).
- **Curiosidades Locais:** Informações e fatos interessantes sobre cidades como Singapura, Xangai, Tóquio, Londres, Praga, Calgary, Joinville, entre outras.
- **Design Responsivo:** Interface adaptável para diferentes tamanhos de tela.

### 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização, layout em grade e animações de transição.
- **JavaScript:** Lógica de filtragem por categoria e controle interativo do modal de imagens.

### 🚀 Como executar localmente
1. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Abra a pasta do projeto e execute o arquivo `index.html` diretamente no seu navegador.

<a name="english"></a>
## 🇺🇸 English

An interactive web gallery of cities around the world, allowing users to filter destinations by continent and view enlarged images with interesting facts about each location.

🔗 **Live Demo:** [brunossilva12-creator.github.io/GaleriaInterativa](https://github.io)

### ✨ Features
- **Continent Filtering:** Dynamic navigation across all cities or specific filtering by Asia, Europe, and America.
- **Lightbox / Modal View:** Click on images to expand them with next/previous navigation controls (`❮` and `❯`).
- **City Facts:** Interesting information about cities such as Singapore, Shanghai, Tokyo, London, Prague, Calgary, Joinville, and more.
- **Responsive Layout:** Interface adapted for different screen sizes.

### 🛠️ Technologies Used
- **HTML5:** Semantic page structure.
- **CSS3:** Styling, grid layout, and hover/transition effects.
- **JavaScript:** Category filtering logic and interactive image modal controls.

### 🚀 How to run locally
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Open the project folder and launch the `index.html` file in your browser.
